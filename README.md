## 🧠 Java/C → Python: My Observations

Coming from statically-typed languages gave me strong instincts for logic and efficiency. Here's what I've noticed:

| Concept | Java / C | Python |
|---|---|---|
| **Type System** | Static, explicit (`int x = 5`) | Dynamic, inferred (`x = 5`) |
| **OOP** | Rigid — everything in a class | Flexible — functions are first-class |
| **Memory** | Manual (C) / JVM managed (Java) | Garbage collected, simpler |
| **Error Handling** | `try-catch` | `try-except` — more Pythonic |
| **DSA** | Custom implementations | Built-in `list`, `dict`, `collections` |
| **Speed to Prototype** | Slower | Significantly faster |
| **AI/ML Ecosystem** | Minimal | Industry standard |

> 💡 *Key insight: Python rewards readability and speed of experimentation — critical for AI/ML research and prototyping.*
